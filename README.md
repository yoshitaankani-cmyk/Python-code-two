# ATM Transaction Sequence Simulation

## About the Project
The ATM Transaction Sequence Simulation is a Python-based program that simulates basic ATM operations such as depositing and withdrawing money. It maintains the account balance and generates a transaction summary.

## Objectives
- Perform deposit operations.
- Perform withdrawal operations.
- Maintain the account balance.
- Reject invalid transactions.
- Display total deposits and withdrawals.

## Concepts Used
- Variables and data types
- Arithmetic operators
- Conditional statements
- For loop
- User input and output

## How the Program Works
1. The user enters the initial account balance.
2. The number of transactions is entered.
3. The program displays deposit and withdrawal options.
4. The user selects a transaction and enters an amount.
5. The balance is updated according to the transaction.
6. Invalid transactions and insufficient balances are rejected.
7. A final transaction summary is displayed.

## Conclusion
This project demonstrates the use of conditional statements and loops to simulate ATM transactions and maintain account balances.
